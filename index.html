Configuração única

Um HTML. Cardápio para todos.

O GitHub publica a página. O Supabase guarda os cardápios e valida quem pode editar.

  1. Crie um projeto em supabase.com.
  2. Em Authentication → Users, crie seu usuário com e-mail e senha; marque a confirmação do e-mail e copie o ID do usuário.
  3. Preencha os dados abaixo. Baixe o SQL e execute-o no SQL Editor desse projeto.
  4. Verifique a conexão, baixe o HTML configurado e envie apenas esse index.html ao GitHub Pages.

Use somente a chave pública. A chave secret ou service_role não deve ser colocada neste HTML.

Conexão de leitura confirmada. Baixe o HTML configurado. O acesso de edição será conferido ao entrar com sua conta.

No GitHub, publique somente o index.html configurado. Os cardápios são consultáveis por quem tiver o endereço; só as contas autorizadas podem editar. A senha não fica no HTML. A edição online exige conexão com a base configurada. Enquanto ela não estiver conectada, esta página funciona como prévia local.
